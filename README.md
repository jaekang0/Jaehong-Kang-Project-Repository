# Jaehong-Kang-Project-Repository
Collection of Data Science projects completed as apart of Jaehong Kang's Bachelor of Applied Data Science degree

## California Housing Data
This project applies an end-to-end data science workflow to the 1990 California Housing dataset, including data cleaning, feature engineering, exploratory data analysis, and linear regression modelling. Categorical variables were encoded, new density-based features were engineered, and variables were standardised to support comparative analysis. Results indicate that median household income, ocean proximity, and population density are the strongest predictors of median house value, while structural features such as house age and number of rooms have limited explanatory power. Modelling capped house prices highlighted limitations of linear regression under data constraints. 

## Rossman Drug Store Data
This project applies a data science workflow to the Rossmann Stores sales dataset, including data cleaning, feature engineering, exploratory time-series analysis, and supervised regression modelling. Extensive preprocessing was performed on temporal, categorical, and competition-related features, followed by seasonality analysis and customer-sales correlation analysis. Multiple models were evaluated (linear regression, decision trees), with a Random Forest Regressor achieving the best performance (R² ≈ 0.90) for short-term sales forecasting. Results highlight customer volume, promotions, and competition distance as the most influential drivers of sales, while also demonstrating the importance of modelling non-linear relationships in retail forecasting.

## Virtual Internships Data
This project applies data cleaning, feature engineering, exploratory data analysis, natural language processing, and supervised machine learning to predict student performance in a virtual internship simulation. Chat logs were transformed into student- and group-level features using topic frequencies, mentor interaction counts, and text-based metrics, with additional NLP techniques including keyword extraction and named entity recognition. Multiple modelling pipelines were evaluated using stratified sampling, SMOTE, PCA, and classification models (logistic regression, SVM, random forest), with group-level models achieving up to ~73% accuracy. Results highlight that mentor interactions and focused discussion on technical requirements are positively associated with higher performance, while excessive questioning correlates negatively with outcomes, demonstrating the importance of communication quality over volume.

## Catheter Placement Data
This project applies exploratory data analysis and deep learning to detect and classify catheter placement from chest X-ray images using the RANZCR CLiP dataset (30,000+ images). After analysing catheter distributions, patient-level repetition, and catheter tip coordinates, multiple convolutional neural network pipelines were developed using ResNet50 for binary and multi-label classification tasks. The modelling strategy addressed severe class imbalance through upsampling, class weighting, and dataset filtering, with experiments across CVC, ETT, and NGT catheter types. The best-performing multi-label catheter classification model achieved ~74% accuracy, and LIME-based model interpretability confirmed that predictions were driven by clinically relevant anatomical regions, highlighting both the potential and limitations of deep learning for automated medical image analysis.
